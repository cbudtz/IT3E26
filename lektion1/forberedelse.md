# Lektion 1 - Forberedelse

## HTML-intro via freeCodeCamp (ca. 1 time)

Inden første lektion skal du lave begyndelsen af freeCodeCamps HTML-forløb:

**[Responsive Web Design](https://www.freecodecamp.org/learn/responsive-web-design-v9)**
→ kapitlet **HTML** → modulet **Basic HTML**

Lav de første fem blokke — til og med **Understanding the HTML Boilerplate**:

1. Workshop: Curriculum Outline
2. Lab: Debug Camperbot's Profile Page
3. Lecture: Understanding HTML Attributes
4. Lab: Debug Pet Adoption Page
5. Lecture: Understanding the HTML Boilerplate

Så kender du tags og attributter, billeder, links og et HTML-dokuments
grundstruktur, når vi mødes. Resten af modulet (bl.a. *Cat Photo App*) laver
vi sammen i lektionen.

> Bemærk: freeCodeCamp kræver login (gratis) for at gemme din fremgang.

## Praktisk

- Medbring din bærbare computer med VS Code installeret. Find det her:
  https://code.visualstudio.com/
- Du behøver ikke kunne HTML på forhånd — forberedelsen ovenfor er nok.
