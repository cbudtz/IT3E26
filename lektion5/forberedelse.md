# Lektion 5 — Forberedelse

## 1. Git med Learn Git Branching (ca. 30 min)

Git er det værktøj, I bruger til at gemme historik og samarbejde om
projektkoden. Gennemfør de tre første dele af **Introduction sequence**:

**[Learn Git Branching](https://learngitbranching.js.org/)**

1. Introduction to Git Commits
2. Branching in Git
3. Merging in Git

Hvis du har tid, så kig kort på **Remote** og læg mærke til forskellen på
`push` og `pull`. Du behøver ikke gennemføre hele Remote-forløbet.

Når du er færdig, skal du kunne forklare:

- hvad et commit er
- hvorfor man bruger branches
- hvad en merge gør
- forskellen på et lokalt repository og et remote repository

Vi bruger GitHub-samarbejde i lektionen. Du skal ikke lære konflikter, rebase
eller avanceret Git hjemmefra.

## 2. JavaScript via freeCodeCamp (ca. 45–60 min)

I kan allerede programmere fra C#. Tag starten af JavaScript for at vænne dig
til syntaksen, og hop derefter til DOM og events — det er det, vi bruger i
Lektion 5.

Brug lektionsoversigten aktivt. Spring workshops og resten af certificeringen
over, medmindre det står her.

**[JavaScript](https://www.freecodecamp.org/learn/javascript-v9/)**

### 1. Introduction to JavaScript (~15 min)

Kapitlet **JavaScript** → modulet **Variables and Strings** → lecturen
**Introduction to JavaScript**.

Lav alle fire:

1. What Is JavaScript, and How Does It Work with HTML and CSS?
2. What Is a Data Type, and What Are the Different Data Types in JavaScript?
3. What Are Variables, and What Are Guidelines for Naming JavaScript Variables?
4. How Do let and const Work Differently When It Comes to Variable Declaration, Assignment, and Reassignment?

Læg mærke til forskellene fra C#: typisk ingen typeangivelse på variablen, og
funktioner behøver ikke at være metoder i en klasse.

### Valgfrit: Build a Greeting Bot (~15 min)

Hvis du vil øve `let`/`const` og strenge lidt mere før DOM: samme modul →
workshoppen **Build a Greeting Bot**. Den er ikke påkrævet.

Spring *Introduction to Strings* og resten af Variables and Strings over.

### 2. DOM og klik-events — udvalgte lectures (~15–20 min)

Hop i oversigten til modulet **DOM Manipulation and Events** → lecturen
**Working with the DOM, Click Events, and Web APIs**.

Lav disse (spring resten i den lange liste over):

1. What Is the DOM, and How Do You Access Elements?
2. What Is the Difference Between innerText, textContent, and innerHTML?
3. How Does the addEventListener Method Work?
4. What Are Inline Event Handlers, and Why Is It Best Practice to Use addEventListener Instead?

### 3. Build a Storytelling App (~15–20 min)

Samme DOM-modul → workshoppen **Build a Storytelling App**.

**Øvelsen er i hus**, når appen reagerer på klik, og du kan pege på, hvor
koden finder et element og ændrer indholdet.

Hvis du har ekstra tid: **Build an Emoji Reactor** i samme modul.

Spring *Understanding the Event Object and Event Delegation*, de øvrige
DOM-workshops (fx Rock Paper Scissors) og `fetch`/backend over — det kommer
senere.

## Når du er færdig

Du skal kunne forklare `let`/`const`, hvad DOM'en er, finde et element fra
JavaScript og koble en klik-hændelse til en ændring på siden.

> Bemærk: freeCodeCamp kræver login (gratis), hvis du vil gemme din fremgang.
