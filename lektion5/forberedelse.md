# Lektion 5 — Forberedelse

## 1. Git med Learn Git Branching (ca. 30 min)

Git er det værktøj, I bruger til at gemme historik og samarbejde om
projektkoden. Gennemfør de tre første dele af **Introduction sequence**:

**[Learn Git Branching](https://learngitbranching.js.org/)**

1. Introduction to Git Commits
2. Branching in Git
3. Merging in Git

Hvis du har tid, så kig kort på **Remote** og læg mærke til forskellen på
`push` og `pull`. Du behøver ikke gennemføre hele Remote-forløbet.

Når du er færdig, skal du kunne forklare:

- hvad et commit er
- hvorfor man bruger branches
- hvad en merge gør
- forskellen på et lokalt repository og et remote repository

Vi bruger GitHub-samarbejde i lektionen. Du skal ikke lære konflikter, rebase
eller avanceret Git hjemmefra.

## 2. JavaScript-grundlag via freeCodeCamp (ca. 30–45 min)

Gennemfør begyndelsen af freeCodeCamps JavaScript-forløb:

**[JavaScript Algorithms and Data Structures](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures-v8/)**

Arbejd i den indledende del af JavaScript-stoffet med:

- variabler med `let` og `const`
- strings, numbers og booleans
- simple operatorer
- funktioner og `return`
- simple `if`-betingelser

Tænk gerne over forskellene fra C#, som du allerede kender: JavaScript
deklarerer normalt ikke variablens type, og funktioner behøver ikke at være
metoder i en klasse.

Stop efter cirka 30–45 minutter. Du behøver ikke nå arrays, objects, DOM eller
`fetch` før lektionen. Det tager vi sammen og bygger videre på senere.

## Når du er færdig

Du skal kunne læse et kort JavaScript-eksempel og forklare, hvad variabler,
funktioner og en simpel betingelse gør.

> Bemærk: freeCodeCamp kræver login (gratis), hvis du vil gemme din fremgang.
