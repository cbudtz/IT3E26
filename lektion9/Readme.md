# Lektion 9 — Klient-tilstand og en URL

Data i mockuppet skal kunne blive i browseren, layoutet skal kunne stå side
om side, og login-formularen skal blive på siden. Til sidst får prototypen
en URL på Vercel. Der er stadig ingen egen backend.

## Forberedelse

Det forventes, at du har forberedt dig — `localStorage`, flexbox og
`preventDefault()` (ca. 50 min).
