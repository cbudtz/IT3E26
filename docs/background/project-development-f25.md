# Projektudviklingsmateriale — F25

> Source: [62410 CDIO Projekt F25 Google Drive folder](https://drive.google.com/drive/folders/10jfMp-e9lRdwoUaIA5nbBXn_hxnhLV6L).
> The most relevant source for L1 is **Aflevering 1 — Projektplan / Project
> Scope / Prototype design** and the accompanying planning material.

## Relevant for IT3E26

The F25 assignment asks students to submit a short project plan containing:

- a **Project Scope Statement**
- an overall project description and project goal
- identified key stakeholders and their needs
- communication requirements: when, how often and to whom
- an initial project plan with milestones
- a first prototype or design sketch
- a group contract

The assignment also asks students to identify a project leader, break work
into manageable tasks, estimate time, assign responsibilities and record
dependencies. These are useful later project-work practices, but should not
all be taught in the first lesson.

## Adaptation for E26 L2 and L4

L1 remains a pure HTML introduction. The relevant project method starts in L2
with **scope definition**, not a complete project management course. Groups
should answer:

1. What problem are we trying to solve?
2. Who is the target user or stakeholder?
3. What is the main goal of the system?
4. What is explicitly inside the scope?
5. What is explicitly outside the scope?
6. What must the first prototype help us learn?

The output can be a short scope statement and a first prototype brief. This
supports D1, which is a clickable frontend mockup without a backend.

## Delayed material

- Detailed Gantt planning and hour accounting: introduce in L4, after the
  scope boundaries are clear.
- Risk analysis, communication and group contract: introduce in L6, when the
  groups have a concrete project to manage.
- Detailed progress tracking: use as the project develops and revisit in the
  status work after each milestone.
- UML and sequence diagrams: assume the prerequisite knowledge and use only
  when needed by the project; do not make them a dedicated L1 topic.

The original F25 assignment also contains an ethics section and a robotics
specific prototype description. These should not be copied directly into
IT3E26; adapt them to digital systems, health technology, privacy and the
selected project case.
